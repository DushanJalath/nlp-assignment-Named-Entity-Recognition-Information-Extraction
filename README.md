# 🔍 NER Information Extraction System

A modular Natural Language Processing application that performs Named Entity Recognition (NER) and information extraction from unstructured text. Built with Python and NLTK, this system identifies entities (persons, organizations, locations), extracts relationships between them, and provides comprehensive visual analytics.

## ✨ Features

- **Text Preprocessing & POS Tagging**: Tokenization, cleaning, and part-of-speech analysis
- **Entity Extraction**: Automatic identification of persons, organizations, and locations
- **Relation Extraction**: Discovers relationships between entities (e.g., "Steve Jobs founded Apple")
- **Visual Analytics**: Generates bar charts and word clouds for entity distribution
- **Export Capabilities**: Creates detailed CSV reports for further analysis

## 🛠️ Technologies

- Python 3.x
- NLTK (Natural Language Toolkit)
- Matplotlib (Visualization)
- WordCloud (Text visualization)
- Pandas (Data manipulation)

## 🎯 Use Cases

- Information extraction from news articles
- Document analysis and summarization
- Knowledge graph construction
- Research paper analysis
- Social media content analysis
